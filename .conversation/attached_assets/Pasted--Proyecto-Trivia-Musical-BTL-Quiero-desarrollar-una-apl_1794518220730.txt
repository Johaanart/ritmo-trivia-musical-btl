# Proyecto: Trivia Musical BTL

Quiero desarrollar una aplicación web para una experiencia BTL de trivia musical inspirada en Spotify. Vamos a construirla por etapas, manteniendo una arquitectura organizada y preparada para integrar posteriormente Supabase, GitHub y Vercel.

## Primera fase: estructura inicial y minijuego

**Tecnologías:**
- React.
- Vite.
- JavaScript.
- CSS moderno y responsive.

**Objetivo:**

Construye la estructura inicial de la aplicación y una primera versión visual y funcional del juego de trivia musical.

### Requisitos de interfaz

1. Diseña una página de inicio con una estética moderna inspirada en Spotify: fondo oscuro, elementos verdes, tipografía clara y componentes visuales atractivos. No utilices logotipos ni recursos protegidos de Spotify.
2. Crea una pantalla principal de trivia.
3. Incluye un reproductor de audio con controles de reproducir y pausar.
4. Muestra cuatro opciones de respuesta para adivinar la canción.
5. Incluye un temporizador por pregunta.
6. Muestra la puntuación del jugador.
7. Proporciona retroalimentación visual cuando la respuesta sea correcta o incorrecta.
8. Incluye una pantalla de resultados al finalizar la partida.
9. Añade una opción para volver a jugar.

### Requisitos técnicos

- Divide la aplicación en componentes reutilizables.
- Mantén separada la lógica del juego de los componentes visuales.
- Utiliza datos de prueba para las preguntas.
- Prepara la estructura para incorporar posteriormente archivos de audio reales.
- No integres todavía Supabase ni servicios externos.
- No inventes enlaces de canciones: utiliza audios de prueba locales o deja identificados los espacios donde se incorporarán.
- Organiza adecuadamente las carpetas y los archivos.
- Asegúrate de que la aplicación funcione correctamente en escritorio y dispositivos móviles.

### Organización esperada

Crea una estructura clara para componentes, páginas, datos, estilos y lógica del juego.

Al terminar:
1. Ejecuta la aplicación y comprueba que funciona.
2. Explícame qué archivos creaste y cuál es la responsabilidad de cada uno.
3. Indícame cómo ejecutar el proyecto.
4. Señala qué queda preparado para las siguientes fases.

No avances todavía con autenticación, base de datos, analítica ni despliegue. Primero necesitamos una base visual y funcional estable.
